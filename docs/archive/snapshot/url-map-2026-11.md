# Bảng ánh xạ URL API cũ → mới (ADR-0022, GĐ4)

API chia theo cổng `/api/{auth,public,candidate,employer,admin,shared}/` và bỏ tiền tố
phiên bản `/api/v2/`. Không giữ alias cũ: frontend đổi cùng PR. URL SEO ngoài `/api` giữ
nguyên, trừ hai route legacy `/jobs` và `/jobs/<slug>` (thay bằng `/viec-lam`). API-root
của DRF router (`/api/admin/`, `/api/v2/`) bị gỡ vì router chuyển sang `SimpleRouter`.

Bảng sinh tự động từ resolver Django: route cũ và mới ghép theo tên route + view.
